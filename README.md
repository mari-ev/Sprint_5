# Автоматизированные тесты Selenium для сервиса «Доска»

## Описание проекта
Проект представляет собой набор автоматизированных тестов для веб-приложения «Доска», реализованных с использованием Selenium и PyTest. Сервис доступен по адресу: [https://qa-desk.education-services.ru/](https://qa-desk.education-services.ru/).

## Особенности реализации

В проекте реализована чёткая структура для удобства поддержки и масштабирования:

* Тестовые данные хранятся в `data.py`, что исключает дублирование и упрощает внесение изменений.
* Генерация данных вынесена в `data_generation.py` с использованием библиотеки Faker — это позволяет создавать разнообразные наборы данных для тестирования.
* Вспомогательная логика (регистрация, выход из системы и т. д.) вынесена в `helpers.py`, что разгружает тесты и фикстуры от рутинных операций.
* Локаторы элементов централизованно хранятся в `locators.py` — изменение селектора требует правки только в одном месте, что снижает риск ошибок при рефакторинге UI.
* Константы (базовый URL, таймауты ожидания, лимиты и т. д.) вынесены в `constants.py` для удобства настройки параметров теста.
* Фикстуры в `conftest.py` отвечают за подготовку тестового окружения: инициализацию драйвера, настройку неявных ожиданий, очистку ресурсов после тестов.
* Управление ресурсами (драйвером браузера) полностью делегировано фикстурам — это предотвращает утечки памяти и гарантирует корректное закрытие сессий.

## Технические требования


* Python 3.14.5
* Google Chrome актуальной версии
* ChromeDriver, совместимый с установленной версией Chrome

## Зависимости проекта


Проект использует следующие библиотеки:
* **Faker** — генерация тестовых данных;
* **pytest** — фреймворк для тестирования;
* **selenium** — автоматизация браузера;
* **webdriver-manager** — управление WebDriver.

Все зависимости устанавливаются командой:
```bash
pip install -r requirements.txt

## Инструкция по запуску
* Запуск всех тестов:
```bash
pytest tests/
```

или

```bash
py -m pytest tests/
```


* Запуск отдельного теста:
```bash
pytest tests/test_*.py
```

* Запуск отдельного теста:

```bash
pytest tests/test_auth.py
```

* Подробный вывод (verbose) — покажет детализацию по каждому тесту:

```bash
pytest -v tests/
```
